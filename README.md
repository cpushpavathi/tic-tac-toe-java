# Tic Tac Toe Game in Java
---
## 📌 Overview
This project is a console-based Tic Tac Toe game developed using Java. It supports two modes:
- Human vs Human
- Human vs AI (Computer Player)

The project demonstrates strong use of Object-Oriented Programming concepts and clean game logic.

---

## 🎮 Features
- Two-player gameplay (Human vs Human)
- Single-player mode against AI
- Dynamic board display
- Valid move checking
- Win and draw detection
- Modular and reusable code structure

---

## 🧠 Concepts Used
- Object-Oriented Programming (OOP)
- Abstraction using abstract classes
- Inheritance and polymorphism
- Encapsulation
- Java control structures and loops

---

## ⚙️ Technologies
- Java
- Console-based input/output

---

## ▶️ How to Run
1. Clone the repository
2. Open the project in any Java-supported IDE (Eclipse / IntelliJ / VS Code)
3. Run:
   - `LaunchGame.java` for Human vs Human
   - `LaunchAI.java` for Human vs AI

The AI player generates random valid moves using Java's `Random` class. This simulates basic computer gameplay and focuses on demonstrating game logic rather than complex AI algorithms.
